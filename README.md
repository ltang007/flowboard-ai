# Flowboard AI

What I would like you to do is build a Kanban board. I’d like to have a to-do and in-progress. First, I’d like you to ask me questions to clarify your understanding. I want the design to be gorgeous and interactive with AI chatbot that response to user’s questions. I want to have the ability to save this information in a database at any time, so I can come back and use it in the future.
